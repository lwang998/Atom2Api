Atom2Api 使用说明
==============================================

本包内含两个程序，任选一种方式使用：

一、桌面模式（推荐，双击即用）
  1. 双击 Atom2Api.exe：自动启动后台服务并打开管理台窗口，关闭窗口即全部退出
  2. 本机访问免登录，直接进入管理台
  3. 「账号管理」连接 AtomGit 完成 OAuth 授权
  4. 「密钥管理」创建 API Key（sk-atom2-* 开头），明文只显示一次

二、服务模式（挂机/服务器）
  1. 直接双击 atom2api-server.exe（或配合计划任务 / nssm 运行）
  2. 浏览器打开 http://localhost:8080 进入管理台（本机同样免登录）

数据存放（两种模式共用）：
- 配置与数据库位于用户目录的隐藏文件夹：C:\Users\<用户名>\.atom2api\
  （config.json 与 data\atom2api.db，首次运行自动生成）
- 升级替换程序无需迁移数据；备份保存整个 .atom2api 文件夹即可

客户端接入：
  OpenAI 兼容:  http://localhost:8080/v1
  Anthropic:    http://localhost:8080（Claude Code 设 ANTHROPIC_BASE_URL 指向它）
  API Key:      sk-atom2-你的密钥

  Claude Code:
    set ANTHROPIC_BASE_URL=http://localhost:8080
    set ANTHROPIC_AUTH_TOKEN=sk-atom2-你的密钥

安全提醒：
- 本机访问管理台免登录；局域网或公网访问管理台仍需密码
- 若置于反向代理之后对外提供，请设置环境变量 ATOM2API_REQUIRE_LOGIN=1
  强制管理台一律走密码登录
- 服务默认明文 HTTP，公网部署必须置于 HTTPS 反向代理之后

兼容说明：工作目录下已存在 config.json 时优先使用它（兼容旧部署）；
也可用 ATOM2API_CONFIG 环境变量指定配置路径。
